# Иконки символов и промыслов

Слоты в разделе «Малая родина». Пока файла нет — на его месте пунктирная рамка.
Положить файл сюда, и он подхватится сам: править код не нужно.

| Файл | Слово |
|------|-------|
| `samovar`  | Самовар |
| `pryanik`  | Пряник |
| `oruzhie`  | Оружие |
| `levsha`   | Левша |
| `keramika` | Керамика |
| `vsechka`  | Всечка |
| `garmon`   | Гармонь |

Отдельно: `memorial` — обелиск на Красном холме, стоит в рамке связей раздела «Здание».
Он не слот, а обычная картинка в разметке, и по имени не подхватывается.

**Имя файла — строчными.** На macOS регистр не различается и `Pryanik.png` подхватится,
а на GitHub Pages файловая система регистрозависимая, и там будет 404.

Расширение любое из: `webp`, `png`, `svg` — проверяются в этом порядке.
Растровые кладите в `webp` с альфой: 320×320 хватает с запасом (слот 138 px, на ретине 276 px),
и весит он вчетверо меньше исходного PNG.

Показывается вписанной в квадрат 138×138, пропорции сохраняются.
В покое иконка на 60% размера, при наведении дорастает до полного и слегка кренится.
Угол задаётся переменной `--rot` у слота в `styles.css`, по умолчанию 4° вправо:

| Слот | Угол |
|------|------|
| samovar, keramika | 4° вправо |
| garmon | 3° вправо |
| pryanik, vsechka | 4° влево |
| oruzhie | 5° влево |
| levsha | не поворачивается |
Цвет растровой иконки задаётся самим файлом; у `svg` с `fill="currentColor"`
цвет подхватится от слота — латунь, при наведении золото.
