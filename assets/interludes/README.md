# Перебивки

Кадр во весь слайд перед разделом или после него. На сайте он идёт во всю ширину
экрана между разделами, в PDF занимает отдельную страницу без полей.

Слот пустой, пока здесь нет файла с его именем: пустая перебивка не показывается
и лишней страницы в PDF не делает. Положить файл — и слайд появится сам,
разметку править не нужно.

**Имя файла** — раздел плюс `-open` (перед разделом) или `-close` (после него):

| Раздел | Перед | После |
|--------|-------|-------|
| Малая родина | `city-open` | `city-close` |
| Концепция целиком | `concept-open` | `concept-close` |
| — «Сюжетная основа» | `story-open` | |
| — «Адаптация мифа» | `myth-open` | |
| — «Персонажи и образы» | `cast-open` | |
| Контекст | `setup-open` | `setup-close` |
| Тема | `theme-open` | `theme-close` |
| Визуальный язык | `lang-open` | `lang-close` |
| Цвет | `color-open` | `color-close` |
| Текстуры | `tex-open` | `tex-close` |
| Раскадровка | `storyboard-open` | `storyboard-close` |
| Звук | `sound-open` | `sound-close` |
| Инструменты | `tools-open` | `tools-close` |
| Финал | `end-open` | `end-close` |

Расширение любое из: `webp`, `jpg`, `png` — проверяются в этом порядке.
**Кладите JPEG**: Chrome переносит его в PDF потоком как есть, а PNG и WebP
распаковывает и кладёт без потерь — два кадра весили в файле 5 МБ вместо 300 КБ.
Из готового PNG: `ffmpeg -i кадр.png -q:v 4 кадр.jpg`, исходник потом удалить.
**Имя файла строчными**: на macOS регистр не различается, на GitHub Pages — да.

Кадр показан так же, как модель на обложке: вписан по центру и растворяется
по краям — не обрезается и не растягивается на весь лист. Формат — горизонтальный
1920×1080.

Растворение краёв делает вёрстка, и в PDF тоже: на сайте — маска `.render`,
на слайде — крестовина из двух градиентов поверх кадра (маску Chrome в печати
теряет, а градиенты переносит — проверено на готовом файле). Так что резкая
граница рендера по краю кадра не страшна, её съест затемнение. Но чем темнее
края в самом файле, тем мягче стык.

**Каждая перебивка добавляет страницу в PDF.** После того как положили файл:
пересобрать `../../build-pdf.sh`, поправить ожидаемое число страниц в нём
и номера страниц в разделе «Содержание» (`.toc__p` в `index.html`).
