# Звуковая дорожка

Проигрыватель в разделе «Звук». Одна дорожка на всё произведение, без меток:
кнопка, полоса воспроизведения и время.

Слот пустой, пока здесь нет файла: блока не будет ни на сайте, ни в PDF.
Положить файл — и проигрыватель появится сам, разметку править не нужно.

**Имя файла** — `track`. Расширение любое из: `mp3`, `m4a`, `ogg`, `wav` —
проверяются в этом порядке, берётся первое, которое браузер умеет играть.

**Кладите `mp3`**: его понимают все браузеры, включая Safari. `ogg` в Safari
не играет, `wav` не сжат и весит в десять раз больше.

Из исходника: `ffmpeg -i дорожка.wav -b:a 128k -ac 2 track.mp3`.
128 kbps на 2,5 минуты — около 2,3 МБ. Выше 192 kbps смысла нет: разницу
на слух не поймать, а вес репозитория растёт.

**Имя файла строчными**: на macOS регистр не различается, на GitHub Pages — да.

## О чём помнить

- **Автозапуска не будет.** Браузеры не дают начать воспроизведение без
  действия пользователя, и обходить это не нужно — дорожка стартует по клику.
- **В PDF проигрывателя нет** — на бумаге звук не играет, и немая полоса
  обещала бы то, чего в файле нет. Ссылка на интерактивную версию есть
  на обложке, страниц в PDF от этого не прибавляется.
- **Пересобирать PDF после добавления файла не нужно** — в печать блок
  не попадает, число слайдов не меняется.
