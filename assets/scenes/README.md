# Сюда кладутся кадры раскадровки

Просто закинуть файл в эту папку и назвать по номеру сцены. Ничего в коде править не нужно —
презентация сама подхватит файл при открытии страницы.

## Имена файлов

| Файл | Куда встанет |
|------|--------------|
| `s01.*` | Сцена 01 — Тьма и первая искра |
| `s02.*` | Сцена 02 — Дикий огонь |
| `s03.*` | Сцена 03 — Горн: приручение |
| `s04.*` | Сцена 04 — Расплав по колоннаде *(готовая сцена)* |
| `s05.*` | Сцена 05 — Застывание во всечку |
| `s06.*` | Сцена 06 — Латунь и пар *(готовая сцена)* |
| `s07.*` | Сцена 07 — Пряничный рельеф |
| `s08.*` | Сцена 08 — Филимоновская вспышка *(пик)* |
| `s09.*` | Сцена 09 — Зеркало *(финал)* |

Регистр важен: `s01`, а не `S01` или `s1`.

## Форматы

**Картинки:** `jpg`, `jpeg`, `png`, `webp`, `avif`, `gif`
**Видео:** `mp4`, `webm`, `mov`

Видео имеет приоритет: если лежат и `s04.mp4`, и `s04.jpg` — на странице крутится видео,
а картинка становится постером и уходит в PDF (видео в печать не попадает).
Поэтому для сцен 04 и 06 стоит положить оба файла.

## Пропорции

**16:9** — под кадры рендера, 1920×1080 px.

Кадр не обрезается: он вписывается целиком (`object-fit:contain`), поэтому файл
любых пропорций встанет корректно. Поля по краям не видны — изображения выводятся
в режиме наложения Screen, и чёрное сливается с фоном.

Для PDF-слайдов хватает исходника шириной ~1920 px.
Файлы тяжелее ~5 МБ лучше сжать, иначе печать в PDF будет долгой.

## Заглушка

Пока своего кадра для слота нет, в рамке стоит `assets/setup.png` — рабочая модель
фасада, приглушённая, с подписью слота поверх. Как только положите файл с нужным
именем, заглушка заменится на него.

Класть `setup.png` в эту папку не надо: она только для кадров `s01`…`s09`.

## Если файл не подхватился

- проверить имя и регистр;
- открывать страницу через Live Server, а не двойным кликом (некоторые браузеры
  ограничивают доступ к файлам по `file://`);
- обновить страницу с очисткой кэша — Cmd+Shift+R.
