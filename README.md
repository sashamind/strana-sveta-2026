# Тула — отражение огня

Презентация проекта 3D-мэппинга на фасаде Штаба Гвардейского корпуса (Дворцовая площадь, Санкт-Петербург).
Конкурс современного медиаискусства «Страна СВЕТА» 2026, второй тур.

**Автор:** Александр Миндрин · Тула
**Тема конкурса:** «Отражение в искусстве»
**Хронометраж проекта:** 2 мин 30 сек

---

## Структура

```
priruchenny-ogon/
├── index.html            — разметка и весь текст презентации
├── css/styles.css        — стили, включая слайды для PDF
├── js/main.js            — шкала, скраббер, кадры, лайтбокс, появление блоков
├── build-pdf.sh          — пересборка PDF
├── priruchenny-ogon.pdf  — готовый файл, который отдаёт кнопка
├── assets/setup.png      — рабочая модель фасада: обложка и заглушка кадров
└── assets/scenes/        — кадры раскадровки (сюда класть свои файлы)
```

`assets/setup.png` — серый clay-рендер фасада. Стоит по центру обложки и подставляется
в каждый пустой слот раскадровки, пока туда не положен свой кадр. Заменить рендер —
просто положить другой файл под тем же именем.

Картинки и видео выводятся в режиме наложения **Screen**: чёрный фон рендера
растворяется в фоне страницы, остаётся только освещённый объём. Если положить кадр
со светлым фоном, он будет выглядеть иначе — режим задан у `.frame img,.frame video`
и у `.hero__stage img` в `styles.css`.

## Что на странице

- **Шкала укрощения** справа — прогресс чтения плюс навигация: у каждого раздела своя
  засечка, при наведении всплывает название, по клику — переход. Градиент шкалы повторяет
  драматургию: уголь → пламя → золото → латунь → филимоновский цвет → зеркало.
- **Тон страницы** плавно меняется по мере прокрутки по той же шкале — внизу экрана
  идёт тёплое зарево, остывающее к финалу до зеркального синего.
- **Скраббер раскадровки** — липкая полоса 2:30 над сценами. Девять сегментов
  пропорциональны длительности, у каждого свой цвет состояния, так что вся драматургия
  читается одной цветной партитурой. Показывает текущий таймкод и название сцены,
  по клику на сегмент — переход к сцене.
- **Фокус чтения** — блок под центром экрана горит в полную силу, остальные гаснут.
  При прокрутке затемнение сильное, в покое смягчается, чтобы не мешать читать.
- **Кадры** открываются во весь экран по клику (когда файл положен в `assets/scenes/`).
  Закрытие — Esc или клик по фону.
- **Раздел «Цвет»** показывает температурную шкалу работы: градиентную полосу от угля
  к зеркалу, семь образцов с кодами и указанием, где каждый цвет звучит, и три правила
  работы с цветом.
- **Финал** построен на этом же фокусе: цитата держит экран одна, выходные данные
  проявляются, когда доходишь до них.
- **Обложка собирается при загрузке**: сначала всплывает здание, следом сверху вниз
  метка, заголовок, факты и подсказка. Анимируются сами элементы, а не обёртки —
  `transform` или `opacity` на `.hero__stage` изолировали бы Screen у модели.
- **Каждая секция гаснет в чёрное**, когда уходит с экрана. Вуаль создаётся скриптом
  в каждой секции, плотность ведёт переменная `--out`.
  Обложка считается от верхней кромки (она ровно в экран высотой, гасить логично сразу),
  остальные — от нижней: раскадровка втрое выше экрана, и отсчёт сверху зачернил бы её
  прямо во время чтения.
  Сделано вуалью поверх, а не прозрачностью самой секции: `opacity` меньше единицы
  создаёт контекст наложения и отключает Screen у модели.
- Искры на обложке, свет под курсором, подсветка карточек, появление блоков при прокрутке.
  Подсказка «Листайте» уходит, как только начали листать.
  Всё это отключается системной настройкой «уменьшить движение».

### Где что правится

| Что | Где |
|-----|-----|
| Название раздела в шкале | атрибут `data-nav` у `<section>` |
| Тайминг сцены | `data-start` и `data-dur` (в секундах) у `.scene` |
| Цвет состояния сцены | `style="--accent:#…"` у `.scene` |
| Палитра целиком | CSS-переменные в начале `styles.css` |
| Температурная шкала | `--coal`, `--flame`, `--ember`, `--gold`, `--brass`, `--crimson`, `--mirror` — одни и те же цвета собирают боковую шкалу, раздел «Цвет» и градиент в разделе «Цвет» |
| Цвета зарева | массив `STOPS` в `main.js` |
| Магма под текстом | класс `magma` в `styles.css` — им залиты заголовок обложки и финальная цитата |
| Глубина затемнения | `--dim` у `:root` (покой) и у `body.scrolling` (прокрутка) |
| Что затемняется | класс `fb` на блоке в `index.html` |

Сумма `data-dur` по всем сценам должна давать 150 секунд — на это опирается скраббер
(константа `TOTAL` в `main.js`).

## Как запустить

В VS Code — через расширение **Live Server**: правый клик по `index.html` → «Open with Live Server».
Сборка не нужна, это чистые HTML/CSS/JS.

Двойной клик по `index.html` тоже работает, но при этом браузер может не подхватить
кадры из `assets/scenes/` — ограничения протокола `file://`. Для работы с раскадровкой лучше Live Server.

## Как вставить свои кадры

Положить файл в `assets/scenes/` и назвать по номеру сцены: `s01`, `s02` … `s09`.
Править код не нужно — при открытии страницы скрипт сам находит файлы и подставляет их в слоты.

```
assets/scenes/s01.jpg   → сцена 01
assets/scenes/s04.mp4   → сцена 04
```

Расширение любое из: `jpg`, `jpeg`, `png`, `webp`, `avif`, `gif`, `mp4`, `webm`, `mov`.

Скрипт сначала читает список файлов в папке одним запросом — так консоль остаётся чистой.
Если сервер не отдаёт листинг каталога (например, GitHub Pages), он откатывается на перебор
расширений, и в консоли появятся 404 по ненайденным вариантам. Это нормально и ни на что
не влияет: слот просто остаётся с заглушкой.
Видео имеет приоритет над картинкой с тем же именем; картинка при этом становится
постером и уходит в PDF (видео в печать не попадает) — для сцен 04 и 06 стоит положить оба файла.

Слоты, для которых файла нет, остаются плейсхолдерами. Подпись `alt` подставляется
автоматически из заголовка сцены.

Пропорции слота — 16:9. Кадр вписывается целиком и не обрезается, файл любых пропорций встанет корректно.
Сцены 04 и 06 помечены классом `frame--live` — это готовые проработанные сцены, рамка у них ярче.

Подробности и таблица соответствия сцен — в `assets/scenes/README.md`.

## Экспорт PDF

Кнопка «Скачать PDF» внизу справа отдаёт готовый файл `priruchenny-ogon.pdf` —
без диалога печати, сразу в загрузки.

Файл лежит в репозитории и **пересобирается командой**:

```bash
./build-pdf.sh
```

Скрипт поднимает локальный сервер, прогоняет страницу через headless Chrome и кладёт
`priruchenny-ogon.pdf` в корень. В конце проверяет число страниц: должно быть **12**.
Если больше — какая-то секция переросла слайд, надо уплотнить её в блоке `@media print`.

**Пересобирать нужно после каждой правки текста или замены кадров** — иначе на сайте
будет скачиваться старая версия. Если готового PDF нет, кнопка откатывается
на диалог печати, чтобы не вести в 404.

Кнопка скачивает файл через `blob:` — так он гарантированно уходит в загрузки с нужным
именем, а не открывается во вкладке просмотрщика PDF.

**Важно:** по `file://` (двойной клик по `index.html`) скачивание не сработает — браузер
считает каждый локальный файл отдельным источником и игнорирует атрибут `download`,
поэтому PDF просто откроется во вкладке. Нужен Live Server или GitHub Pages.

Формат страницы — 508×285,75 мм, это 1920×1080 px при 96 dpi: 12 тёмных слайдов 16:9
(обложка, город, тема, визуальный язык, цвет, пять слайдов раскадровки, звук, финал).

Вручную то же самое: Cmd+P → **Сохранить как PDF**, поля **Нет**,
**фоновая графика включена** (иначе пропадёт чёрный фон), масштаб 100%.

Разбивка раскадровки задаётся классом `pb` на сценах 03, 05, 07 и 09 — он ставит
разрыв ПЕРЕД сценой, и получается по две сцены на слайд. Три не помещаются: кадр 16:9
высокий. Разрыв именно «перед»: с `break-after` Chrome терял один из четырёх. Перенести `pb` на другие сцены =
другая разбивка, но тогда надо поправить и ожидаемое число страниц в `build-pdf.sh`.

## Технические заметки

- Шрифты подключены с Google Fonts: Cormorant (заголовки), Manrope (текст), JetBrains Mono (таймкоды)
- Палитра в CSS-переменных в начале `styles.css` — правится в одном месте
- Учтён `prefers-reduced-motion`, есть видимый фокус для клавиатуры, адаптив до 900 px.
  Кадры открываются с клавиатуры (Tab → Enter), лайтбокс закрывается по Esc
- Медиазапрос адаптива обязан быть `@media screen and (max-width:900px)`. Без `screen`
  он срабатывает и при печати: сетки схлопываются в одну колонку, и PDF разъезжается
  с 9 слайдов на 16
- `body` намеренно без `overflow-x:hidden` — иначе ломается `position:sticky` у скраббера
